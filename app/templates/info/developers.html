1. Create an HTML conversion task

Send HTML directly, or use urls with one public web address per line. You can also upload an HTML file and include its ID in files.

POST /api/tasks
Content-Type: application/json

{"type":"htmlToPdf","files":[],"htmlCode":"<h1>Invoice</h1>","pageSize":"A4"}

Options include pageOrientation, pageMargin, pageMarginUnits, viewportWidth, delay, lang, timezone, and usePrintMedia. The live catalog lists every available option. Private network addresses and network WebSockets are blocked.

A successful task request returns the task ID as a JSON string. A busy server returns HTTP 429; an enabled hourly quota returns HTTP 402. Invalid input returns HTTP 400.

{{ '2' if html_api else '3' }}. Poll and download

GET /api/tasks/YOUR_TASK_ID/change

Poll every three seconds until status is Completed or Failed. For completed tasks, prefix resultFullUrlPattern with your server's scheme, then replace %7B%7Bfilename%7D%7D with the URL-encoded resultFilename. Multiple results are packaged as a ZIP; individual filenames appear in resultItems.

You can open /result?id=YOUR_TASK_ID in a browser, cancel with POST /api/tasks/YOUR_TASK_ID/cancel, or delete with DELETE /api/tasks/YOUR_TASK_ID.

Keep IDs private

File IDs and task IDs grant access to their files and actions. Treat them like passwords. Anyone with a result link or task ID can retrieve that result until it expires. Do not place confidential task IDs in public logs.

Uploads expire {{ ttl_hours }} hours after their last keep-alive. Results expire {{ ttl_hours }} hours after completion. Task records are held in memory, so restarting the server invalidates task links.
