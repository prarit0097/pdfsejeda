Help & FAQ

Which files can I upload?

Most tools take PDFs. Some also take images (JPG, PNG, GIF, TIFF, BMP, WEBP) or Office files. The upload button shows the types each tool accepts. Files can be up to {{ max_file_mb }} MB.

How do I select pages?

Click page thumbnails, or type a selection: 1-3,7, 10- (to the end), odd, even.

My file is password protected.

After uploading you'll be asked for the password. To remove the password permanently, use Unlock PDF.

Can I use the result in another tool?

Yes. On the result screen choose “Continue in another tool”. To repeat the same chain of tools, create a workflow.

How long are files kept?

{{ ttl_hours|round|int }} hours, then they are deleted automatically.

The result looks wrong.

Try the Repair tool first if the PDF is damaged. For scanned documents, run OCR before converting to Word or Excel.
